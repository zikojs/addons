# Zikojs Addons

## Addons 

- [@zikojs/lucide](https://github.com/zikojs/addons/tree/main/packages/lucide) : Lucide Icons for ZikoJs.
- [@zikojs/p5](https://github.com/zikojs/addons/tree/main/packages/p5) : Reactive p5.js integration wrapper for the ZikoJS framework that turns p5.js sketches into native, state-driven UI components.
- [@zikojs/lottie](https://github.com/zikojs/addons/tree/main/packages/lottie) : Lottie player element for zikojs.
- [@zikojs/atropos](https://github.com/zikojs/addons/tree/main/packages/atropos) : Atropos integration for ZikoJS, create touch-friendly 3D parallax effects and interactive elements.
- [@zikojs/gsap](https://github.com/zikojs/addons/tree/main/packages/gsap) : GSAP adapter for zikojs.
- [@zikojs/mermaid](https://github.com/zikojs/addons/tree/main/packages/gsap) : Mermaid adapter for zikojs.
