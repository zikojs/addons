# Zikojs Addons

A collection of official adapters, reactive wrappers, and declarative components for integrating popular JavaScript libraries into the ZikoJS ecosystem.

## Addons 

- [@zikojs/lucide](https://github.com/zikojs/addons/tree/main/packages/lucide) : Lucide Icons for ZikoJS.
- [@zikojs/p5](https://github.com/zikojs/addons/tree/main/packages/p5) : Reactive p5.js integration wrapper for the ZikoJS framework that turns p5.js sketches into native, state-driven UI components.
- [@zikojs/lottie](https://github.com/zikojs/addons/tree/main/packages/lottie) : Lottie player element for ZikoJS.
- [@zikojs/atropos](https://github.com/zikojs/addons/tree/main/packages/atropos) : Atropos integration for ZikoJS, create touch-friendly 3D parallax effects and interactive elements.
- [@zikojs/gsap](https://github.com/zikojs/addons/tree/main/packages/gsap) : GSAP adapter for ZikoJS.
- [@zikojs/mermaid](https://github.com/zikojs/addons/tree/main/packages/mermaid) : Mermaid adapter for ZikoJS to render flowcharts, diagrams, and sequence charts declaratively.
- [@zikojs/framer-motion](https://github.com/zikojs/addons/tree/main/packages/framer-motion) : Declarative motion primitives, layout animations, and gesture hooks for ZikoJS UI elements.
- [@zikojs/leaflet](https://github.com/zikojs/addons/tree/main/packages/leaflet) : Declarative Leaflet map container and spatial layer components (`Marker`, `Circle`, `Polygon`, `TileLayer`).
- [@zikojs/mind-elixir](https://github.com/zikojs/addons/tree/main/packages/mind-elixir) : Interactive mind map canvas wrapper for ZikoJS featuring declarative node hierarchy components.
- [@zikojs/canvas-confetti](https://github.com/zikojs/addons/tree/main/packages/canvas-confetti) : Declarative particle canvas and preset triggers (`Burst`, `Snow`, `Fireworks`) for ZikoJS.
